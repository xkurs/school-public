Учебный вариант 00 — пара 21

Постоянный пример преподавателя. Тема учебных наборов продолжает пару 20. Объяснения конструкций и порядок самостоятельной работы — в статье пары 21. Номер 00 студентам не назначается: в своём проекте используйте собственные карточки и данные пары 19.

Задание

Создайте небольшой консольный каталог учебных наборов. Программа должна хранить три карточки массивом объектов, показать все карточки одним циклом, найти выбранный набор по точному названию и рассчитать результат только для него функцией пары 20. В конце покажите, сколько записей совпало с выбранным названием. При отсутствии совпадений сообщите об этом; при нескольких — предупредите о повторяющихся названиях.

Программа получает количество как строку в коде. Форма, DOM и события пока не используются. Итог появляется в консоли, а не на HTML-странице.

Данные карточек

Все названия и характеристики синтетические. У каждого объекта одинаковые свойства: position, name, specs, description.

position name specs description
1 Базовый набор Для одного участника Материалы для первого упражнения
2 Расширенный набор Для двух участников Материалы для совместного упражнения
3 Набор для команды Для небольшой группы Материалы для общего проекта

Данные выбора: selectedName — «Базовый набор», quantityText — "2", unitValue — 150 условных рублей за набор, extraValue — 50 условных рублей за одну доставку всего заказа. Цены известны только для выбранного базового набора; характеристик остальных наборов они не определяют. Не добавляйте цену каждому объекту.

Используйте уже собранную функцию getResult(quantityText, unitAmount, extraAmount). Она проверяет пустой ввод, преобразование в конечное число и положительное целое количество. При ошибке возвращает текст причины, при успехе — строку Итого: с результатом формулы «значение на единицу × количество + одна общая добавка».

Порядок выполнения

  1. Создайте catalog.js рядом с учебной HTML-страницей и подключите его в head через script с src="catalog.js" и defer. Для отдельного показа достаточно страницы с заголовком «Учебный каталог» и пояснением о консоли; HTML не должен содержать готовый вычисленный итог.
  2. Перенесите собственное объявление функции пары 20, сохранив её контракт. Ниже создайте массив catalog из трёх объектов по таблице.
  3. Через индекс выведите название первой и последней записи, убедитесь в правильности, затем уберите временный вывод.
  4. Объявите данные выбора и foundCount, начав счётчик с нуля. Покажите количество объектов массива.
  5. Напишите один for...of: для каждого объекта покажите номер и название, характеристику и описание.
  6. В том же цикле сравните название текущего объекта с selectedName. Только при совпадении увеличьте счётчик, выведите выбранное название и возвращённое функцией сообщение. Аргументы вызова: строковое количество, unitValue, extraValue. Отдельно поясните единицу расчёта — условные рубли.
  7. После цикла выведите счётчик, сообщение при нуле и предупреждение при значении больше одного.

Не вписывайте сумму 350 прямо в команду вывода: она должна получиться вычислением. Не печатайте карточки тремя независимыми готовыми блоками: повторение выполняет цикл.

Ожидаемый результат

При исходных данных в консоли находятся три блока карточек. Между блоками могут быть дополнительные подписи; важны содержание и связь с данными. Для выбранной первой записи присутствуют строки:

Текст
Выбрано для расчёта: Базовый набор
Итого: 350
Единица расчёта: усл. руб.

Сначала показано «Записей: 3», после обхода — «Найдено записей: 1». У остальных двух карточек расчёта нет.

Проверка изменением

Изменение перед новым запуском Ожидаемый результат
Количество "3" Итого: 500; найдено 1
Количество " " Ошибка: укажите количество; найдено 1
Количество "два" Ошибка: введите число; найдено 1
Количество "0" или "1.5" Ошибка положительного целого количества; найдено 1
Выбранное название «Нет такого набора» Все три карточки выведены; найдено 0; сообщение об отсутствии записи; расчёта нет
Первые два объекта поменяны местами Блоки идут в новом порядке; рассчитывается всё ещё базовый набор
Название второй записи временно совпадает с первой Найдено 2, два расчёта и предупреждение о повторе

После каждого опыта восстановите исходные данные. Покажите преподавателю массив, один объект, обращение к свойству, условие и счётчик. Объясните, почему неверное количество не меняет число найденных записей. Для быстрого продолжения выберите поиск по части названия или контроль пустых описаний из статьи пары.
