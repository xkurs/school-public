Учебный вариант 00 — пара 21

Постоянный пример преподавателя. Он принадлежит паре 21, сохраняется при смене студенческого комплекта и содержит все файлы для отдельного показа. Объяснение — в статье пары 21. Тема учебных наборов продолжает пример пары 20, но теперь задача состоит в представлении данных каталога.

Задание: описать три записи каталога массивом объектов. Каждая запись хранит видимый порядковый номер position и название name. Вывести количество записей, затем одним циклом — все номера и названия, после цикла — название первой записи через индекс.

Индекс массива начинается с нуля; видимые номера в свойстве position начинаются с единицы. Результат показывается только в консоли. Чтение и изменение HTML, обработка формы, расчёт общей суммы и фильтрация в это задание не входят.

Данные и ожидаемый вывод

Условный каталог сохраняет порядок:

Индекс массива position name
0 1 Базовый набор
1 2 Расширенный набор
2 3 Набор для команды

Ожидаемый вывод:

Записей: 3
1. Базовый набор
2. Расширенный набор
3. Набор для команды
Первая запись: Базовый набор

Файл index.html

Создайте папку Variant00-catalog. В ней создайте index.html и вставьте весь текст:

<!doctype html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Данные каталога · V00</title>
  <script src="catalog.js" defer></script>
</head>
<body>
  <main>
    <h1>Учебный каталог</h1>
    <p>Программа выводит данные в консоли браузера.</p>
    <p>Порядок записей: базовый набор, расширенный набор, набор для команды.</p>
  </main>
</body>
</html>

Этот HTML нужен только для автономного запуска. Студенты подключают catalog.js к существующей главной странице и берут названия из своих прежних карточек; новый HTML-каталог создавать не требуется.

Файл catalog.js

Рядом создайте catalog.js и вставьте весь код:

const catalog = [
  { position: 1, name: "Базовый набор" },
  { position: 2, name: "Расширенный набор" },
  { position: 3, name: "Набор для команды" }
];

console.log("Записей:", catalog.length);

for (const item of catalog) {
  console.log(item.position + ". " + item.name);
}

console.log("Первая запись:", catalog[0].name);

Сохраните оба файла в UTF-8. Откройте index.html, затем F12 → Console / Консоль и обновите страницу. Если клавиша недоступна, откройте инструменты разработчика через меню браузера. Сверьте пять строк с образцом выше.

В массиве три объекта. На каждом проходе item обозначает очередной объект, поэтому одна строка вывода внутри цикла выполняется трижды. В последней команде catalog[0] получает первый объект, а .name читает его название. Свойство position в этой операции не участвует.

Проверка изменением

В исходном тексте catalog.js временно замените название второго объекта на "Расширенный набор тест". Сохраните и обновите страницу. Вторая строка каталога должна измениться, первая и третья — сохранить свои названия. Строка «Первая запись:» тоже не меняется, потому что читает объект по индексу 0.

Верните исходное название, сохраните и обновите страницу. Должны снова появиться пять строк первоначального образца. Мы изменили данные в тексте файла перед новым запуском; это не редактирование страницы программой.

Готово, когда один цикл выводит три записи в правильном порядке, длина равна 3, отдельный доступ к первой записи работает и вы можете указать массив, объект и его свойство. В студенческом проекте вместо этих названий используются названия своих трёх карточек. Отдельный письменный отчёт и дополнительные функции не требуются.
