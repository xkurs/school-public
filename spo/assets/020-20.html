Вариант 20 — Мастерская идей, пара 20

Продолжайте папку Variant20-web и тему «Мастерская идей». Статья объясняет порядок сборки и проверки. Вариант 00 — общий пример преподавателя; свои данные приведены ниже.

Задание

Рассчитайте бюджет выбранного мастер-класса: стоимость материалов одному участнику умножьте на количество участников и прибавьте стоимость одной общей подготовки инструментов.

Добавьте проверку количества: допустимо только положительное целое число. Вместо суммы при неверном вводе нужно вернуть понятную причину отказа. Количество сегодня задано строкой в файле; сообщение показывается в консоли. Чтение формы и обработка кнопки будут позже.

Все числа вымышлены для учебного расчёта. Они не задают настоящие цены, нормы или характеристики каталога.

Ваши данные

Внешнее имя Данные и смысл Тип
itemName Роспись значка string
quantityText "3" — Количество участников string
unitValue 130 — стоимость материалов одному участнику, усл. руб. number
extraValue 60 — одна общая подготовка инструментов, усл. руб. number
isTraining true — признак учебных данных boolean

Результат: Общая стоимость; единица — усл. руб.

Единицы выводите отдельно как текст, числовые величины храните числами. Общая добавка учитывается один раз. Учебный признак в формулу не входит.

Соберите и проверьте

  1. Сохраните прежний script.js. Рядом создайте conditions.js и замените подключение в index.html: оставьте одно подключение текущей программы. Проверьте запуск через консоль браузера.
  2. Объявите свои исходные данные из таблицы. Комментариями подпишите смысл количества, величины на единицу и общей добавки.
  3. Самостоятельно создайте одну функцию getResult(quantityText, unitAmount, extraAmount). Она получает строку количества и две числовые величины, возвращает строку сообщения. Передайте свои quantityText, unitValue, extraValue по порядку. Сохраните возвращённое сообщение в resultMessage и выведите отдельно от функции.
  4. Внутри функции преобразуйте текст в quantity, вычислите totalAmount из параметров и верните сообщение с началом Итого:. Готовый итог из таблицы не подставляйте вместо расчёта.
  5. До преобразования добавьте отказ для пустой строки и одних пробелов. После преобразования — для нечислового и бесконечного значения. Перед формулой добавьте отдельные отказы для неположительного и нецелого количества. Каждый отказ завершает вызов через return, без вычисленной суммы.
  6. Сохраните одиннадцать подписанных испытаний ниже. Затем добавьте два отдельных вызова с изменёнными числовыми аргументами, сохранив исходные константы.

Ожидаемые результаты

В каждом из одиннадцати испытаний передавайте свои неизменённые unitValue и extraValue. Строки в кавычках показывают точное содержимое первого аргумента, включая пробелы.

Два дополнительных испытания выполняйте для строки "2". В каждом меняйте только один числовой аргумент.

Изменение unitAmount extraAmount Возвращённое сообщение
Величина на единицу больше на 10 140 60 Итого: 340
Общая добавка больше на 10 130 70 Итого: 330

По сравнению с двумя единицами на исходных данных первый итог увеличивается на 20, второй — на 10. Это изменение учебных аргументов для проверки зависимости функции, а не новые исходные данные.

Самопроверка

Перед запуском предскажите сообщение. Сохраните файл, обновите страницу и сравните все 13 результатов. Для неверного количества видна причина отказа, а суммы нет. Для пробелов вокруг числа получается тот же итог, что и для двух единиц. Исправьте расхождения и повторите соответствующие испытания. Убедитесь, что функция объявлена один раз, использует параметры и возвращает сообщение; вывод выполняется снаружи.

Покажите преподавателю: подключение conditions.js, самостоятельно собранную функцию, сохранённые испытания и результаты. Проследите путь одного неверного значения до первого выполненного return. Объясните влияние двух числовых аргументов, откуда в будущем придёт строка количества и где пользователь увидит сообщение. Отдельный отчёт не требуется.
