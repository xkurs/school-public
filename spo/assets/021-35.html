Вариант 35 — Снаряжение рядом, пара 21

Продолжайте папку Variant35-web и тему «Снаряжение рядом». Статья объясняет конструкции и порядок работы. Вариант 00 — отдельный пример преподавателя. Все собственные данные для этой работы приведены ниже.

Задание

Создайте catalog.js: массив catalog из трёх объектов своих карточек, один for...of для вывода всех карточек, выбор по точному совпадению name с selectedName и расчёт только совпавших записей. Используйте свою функцию пары 20 getResult(quantityText, unitAmount, extraAmount). Она возвращает строку ошибки или Итого: с результатом: величина на единицу × количество + одна общая добавка.

Рассчитайте бюджет проката выбранного снаряжения: стоимость одного комплекта умножьте на количество комплектов и прибавьте стоимость одной общей подготовки снаряжения.

Все числовые величины расчёта — вымышленные учебные данные. Они известны только для выбранного названия, не определяют цены или нормы остальных карточек. Не добавляйте цены остальным объектам. Форма, DOM и события сегодня не используются.

Данные трёх карточек

У каждого объекта одинаковые четыре свойства. Сохраняйте точные тексты и исходные номера.

position name specs description
1 Коврик 180 см · 1 комплект Для остановки и отдыха на природе
2 Фонарь Три режима · 1 комплект Свет для вечерней прогулки
3 Рюкзак 30 литров · 1 комплект Для вещей и короткого маршрута

Данные выбора и расчёта

Имя Данные и смысл Тип
selectedName Коврик string
quantityText "3" — Количество комплектов string
unitValue 310 — стоимость проката одного комплекта, усл. руб. number
extraValue 70 — одна общая подготовка снаряжения, усл. руб. number

Результат: Общая стоимость; единица — усл. руб.

Единицы выводите отдельным текстом. Общая добавка учитывается один раз.

Соберите программу

  1. Сохраните прежние файлы. Создайте catalog.js рядом с index.html, замените подключение текущей программы на этот файл через script, src и defer. Оставьте одно подключение; итог проверяется в консоли браузера.
  2. Перенесите собственное объявление getResult из пары 20 без прежних проверочных вызовов. Сохраните проверки пустого ввода, конечного числа и положительного целого количества.
  3. После функции самостоятельно соберите массив catalog по таблице. Через индексы проверьте первую и последнюю запись, затем уберите временный вывод.
  4. Перед циклом задайте данные выбора, начните foundCount с нуля, выведите «Записей:» и длину массива.
  5. В одном for...of выводите для каждого текущего объекта исходный номер и название, характеристику и описание. Только при точном совпадении name с selectedName увеличивайте foundCount, показывайте выбранное название, вызывайте getResult со своими quantityText, unitValue, extraValue по порядку и выводите возвращённое сообщение message и единицы. Счётчик считает совпадения даже при ошибке количества.
  6. После цикла покажите «Найдено записей:» и счётчик. При нуле выведите «Запись не найдена:» и выбранное название; при значении больше одного — «Проверьте повторяющиеся названия». При дубле расчёт выполняется для каждого совпадения.

Девять проверочных запусков

Перед каждым запуском предскажите вывод, сохраните файл и обновите страницу. После каждого опыта восстановите исходные данные перед следующим. Во всех запусках выводятся все три карточки и «Записей: 3».

Опыт Что изменить Ожидаемый результат
Исходный запуск Ничего Итого: 1000; Единица расчёта: усл. руб.; один расчёт; Найдено записей: 1
Другой объём quantityText — "4" Итого: 1310; Единица расчёта: усл. руб.; один расчёт; Найдено записей: 1
Пустое поле quantityText — " " Ошибка: укажите количество; Найдено записей: 1; рассчитанного итога нет

Ноль quantityText — "0" Ошибка: нужно положительное целое количество; Найдено записей: 1; рассчитанного итога нет

Повтор названия Только name второй записи временно сделайте «Коврик» Итого: 1000; Единица расчёта: усл. руб. — дважды; Найдено записей: 2; Проверьте повторяющиеся названия

При ошибке количества выбранная запись найдена, но числовой итог не вычисляется. При отсутствии имени функция не вызывается. При перестановке переносите целые объекты, а не отдельные названия: сведения карточки должны оставаться вместе. После дубля верните настоящее название второй карточки.

Покажите преподавателю: подключение catalog.js, три объекта, обращение к свойству, один цикл, условие, вызов функции и счётчик. Объясните результат всех девяти запусков и почему ошибка количества не меняет число найденных записей. Отдельный отчёт не нужен.
