Вариант 05 — Книжная полка, пара 18

Адаптация и проверка в браузере. Продолжайте папку Variant05-web. Сохраните свой номер, тексты, изображения, порядок и начальные значения. Фамилия в приложении не требуется.

Статья объясняет способ выполнения; Вариант 00 показывает работу преподавателя. Здесь — самостоятельное задание вашего номера.

Задание

Адаптируйте прежние три страницы к узкому экрану по статье. Добавьте viewport, перенос меню и гибкий каталог через Flexbox; на узком экране карточки идут по одной. Проверьте главную, каталог и форму на 320, 375 и 768 CSS px. Содержание, палитра, порядок позиций и шести элементов формы сохраняются.

Результат

Каталог — 768 CSS px

Каталог — 375 CSS px

Главная — 375 CSS px

Форма — 375 CSS px

Схемы показывают настоящие данные вашего варианта; это не снимки браузера и не изображения для вставки вместо HTML. Точное совпадение пикселей не требуется. Оранжевый контур формы обозначает фокус после Tab, постоянно показывать его не нужно.

В каждом меню — две ссылки на другие страницы: «Главная», «Каталог», «Форма» без ссылки на открытую страницу. У каждой страницы один h1 внутри main и понятный title с названием приложения и номером.

Сохраните PNG по ссылкам в Variant05-web/images под прежними именами из таблицы. Имя скачанного файла может быть длинным хешем: переименуйте его в указанное имя; для главной нужен item1.png. Используйте все три позиции строго в указанном порядке; изображения сохраняют пропорции. У каждой позиции — отдельный article.card, h2, изображение с содержательным alt, характеристика p.specs и описание p.description.

Содержание формы

Название — «Заявка на книгу». Шесть элементов идут сверху вниз строго в порядке строк.

Порядок Видимая подпись Элемент Данные и начальное состояние
1 Количество экземпляров Числовое поле Целое количество от 1; шаг 1; начальное значение 3; поле обязательно
2 Пожелания к выдаче textarea Подсказка: «Опишите ваши пожелания»; заполнение необязательно
3 Название книги select Первая строка — пустой выбор; затем Путешествие к морю; Город будущего; Тайна старого дома. Выбор обязателен
4 Объём книги Ползунок От 1 до 5; начальное значение 3. Края: «Короткая» и «Большая»
5 Нужна закладка Независимый флажок Выбран в начале
6 Нужен крупный шрифт Независимый флажок Не выбран в начале

После элементов — кнопка «Оставить заявку»; за формой — ссылка «Назад» на index.html. Сохраните видимые подписи, связи for и уникального id, атрибуты name и проверку ввода. Список начинается с пустого выбора, количество — обязательное целое от 1 с шагом 1. Комментарий необязателен; подсказка не заменяет подпись. Флажки переключаются независимо. GET показывает параметры в адресе без сервера, хранения и обработки; данные учебные, вымышленные.

Перед сдачей откройте инструкцию проверки размеров и сдачи работы. В ней показано, где включить панель устройств, куда вводить 320, 375 и 768 и что показать преподавателю.
