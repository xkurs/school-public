Вариант 01 — На тропе, пара 19

Продолжайте папку Variant01-web и тему «На тропе». Статья объясняет переменные, типы, подключение файла и преобразование строки.

Задание

Самостоятельно создайте и сохраните script.js рядом с главной страницей, подключите его к index.html. Программа выполняется при обновлении главной и показывает результат в консоли браузера.

Рассчитайте общую стоимость участия в выбранном маршруте: стоимость для одного участника умножьте на количество участников и прибавьте один общий организационный сбор.

Все числа ниже вымышлены для учебного расчёта. Они не задают настоящие цены, нормы или характеристики каталога.

Ваши данные

Имя значения Содержание Тип
itemName Лесная тропа string
quantityText "2" — Количество участников string
unitValue 450 — стоимость участия одного человека, усл. руб. number
extraValue 100 — один общий организационный сбор, усл. руб. number
isTraining true — признак учебных данных boolean

Выберите const для неизменяемых значений и let для строки количества. Перед вычислением явно преобразуйте quantityText с помощью Number и сохраните число под именем quantity. Вычисленный итог сохраните под именем total. Учебный признак только выводится и не меняет расчёт.

Что вывести

Подпись в консоли Значение
Название Лесная тропа
Учебные данные true
Количество участников Числовое количество quantity
Общая стоимость Вычисленный total, единица — усл. руб.
Тип строки количества string
Тип количества после преобразования number
Тип итога number
Тип учебного признака boolean

Используйте typeof для проверки типов. Единицы измерения выводите как текст; числовой итог храните числом.

Самопроверка

Ожидаемый текст консоли при проверочном запуске:

Для строки количества "2":

Название: Лесная тропа
Учебные данные: true
Количество участников: 2
Общая стоимость: 1000 усл. руб.
Тип строки количества: string
Тип количества после преобразования: number
Тип итога: number
Тип учебного признака: boolean

Запустите программу с исходной строкой "2": сохраните файл и обновите страницу. Постоянная добавка учитывается один раз. Сверьте результат и типы с образцом выше. Сохраните проект.

Покажите преподавателю подключение файла, самостоятельно написанную программу и результат одного проверочного запуска в консоли. Объясните, зачем преобразовывать строку в число. Отдельный отчёт не требуется.

На этой практике используйте только значения, арифметические операции, преобразование и вывод в консоль. Чтение полей формы, DOM, события, условия, циклы и функции здесь не нужны.
