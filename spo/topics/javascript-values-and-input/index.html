JavaScript — переменные, типы, операции и преобразование пользовательского ввода

HTML задаёт содержимое страницы, CSS — оформление, JavaScript позволяет выполнять действия и вычисления. На этой практике сохраним первый script.js и проверим небольшой расчёт в консоли браузера.

Результат: файл вычисляет стоимость двух учебных наборов с доставкой. Вы сможете изменить количество и объяснить, почему строку перед расчётом нужно преобразовать в число.

Продолжайте свою папку VariantNN-web после адаптации страниц. Для первого расчёта у всех одинаковые вымышленные данные: один набор стоит 150 условных рублей, доставка — 50. Это отдельный учебный опыт: добавлять цены товарам своего варианта и переделывать форму не требуется.

Вариант 00 содержит самостоятельное задание, HTML-страницу и готовый код для показа преподавателем.

1. Подключите файл

В своей папке рядом с index.html и style.css создайте обычный текстовый файл script.js. Проверьте расширение: script.js.txt браузер не найдёт по нашему пути.

В index.html, между <head> и </head>, сразу после подключения CSS добавьте одну строку:

<script src="script.js" defer></script>

src указывает путь к файлу. defer откладывает выполнение до завершения разбора HTML. Вставлять JavaScript внутрь этого тега не нужно: программа хранится в отдельном файле. На этой практике достаточно подключить её на главной странице.

В пустом script.js напишите:

console.log("Расчёт запущен");

Сохраните оба файла. Откройте главную в браузере, нажмите F12 и выберите вкладку Console / Консоль. Если F12 не открывает инструменты, используйте меню браузера → дополнительные инструменты → инструменты разработчика. Обновите страницу.

Самопроверка: в консоли есть строка «Расчёт запущен». На самой странице новый текст не появляется: console.log(...) выводит сообщение в консоль. В скобках — то, что нужно вывести; точка с запятой завершает команду.

2. Дайте значениям имена

В script.js замените пробную строку следующим блоком:

const itemName = "Учебный набор";
const unitPrice = 150;
let quantityText = "2";
const deliveryPrice = 50;
const isTraining = true;

console.log(itemName);
console.log(quantityText);
console.log(isTraining);

Переменная — именованное место для значения. = записывает значение справа в имя слева. Команды выполняются сверху вниз.

Запись Что означает
const unitPrice = 150; Объявить имя unitPrice и записать число 150; повторное присваивание запрещено
let quantityText = "2"; Объявить имя quantityText и записать строку; позже можно присвоить другое значение
console.log(unitPrice); Посмотреть значение по его имени

Имена чувствительны к регистру: unitPrice и UnitPrice — разные имена. В числах не пишем единицу измерения: 150, а не 150 рублей. Текст записываем в кавычках.

Сохраните файл и обновите страницу. В консоли должны появиться название, количество и true. Вид кавычек и цвет значений зависят от браузера.

Маленький опыт: сразу после строки let quantityText = "2"; временно вставьте:

quantityText = "3";

После сохранения и обновления выводится уже 3. При повторном присваивании let не пишут. Удалите временную строку и обновите страницу: снова выводится 2. const используем там, где повторного присваивания в программе не планируем. Редактировать исходный текст строки с const перед новым запуском можно.

3. Различайте три типа

Значение имеет тип: он определяет, как с ним работает программа.

Тип Примеры Назначение
Строка — string "Учебный набор", "2", "" Текст, включая цифры в кавычках; "" — пустой текст
Число — number 150, 2, 1.5 Вычисления; дробная часть отделяется точкой
Логическое значение — boolean true, false «Да» или «нет», без кавычек

isTraining = true обозначает, что пример учебный. Пока мы только выводим этот признак: он не меняет формулу.

В конец script.js, после трёх строк вывода, добавьте:

console.log(typeof quantityText);
console.log(typeof unitPrice);
console.log(typeof isTraining);

typeof показывает тип значения. Сохраните и обновите страницу. Последние три строки консоли — string, number, boolean. Поэтому одинаково выглядящие при выводе "2" и 2 ещё не означают одинаковые данные.

4. Проверьте сложение и преобразование

Следующие два выражения вводите по одному в строку консоли браузера, нажимая Enter. Перед запуском попробуйте предсказать результат:

"2" + 1

Number("2") + 1

В первом случае получится строка "21": + присоединяет текст, если один из этих операндов — строка. Во втором — число 3: Number("2") преобразует строку в число, и затем выполняется сложение.

"2" — строка → Number("2") → 2 — число → 2 + 1 → 3

При чтении значения поля веб-страницы программа обычно получает строку, даже если это числовое поле. К чтению полей перейдём позже. Сейчас quantityText = "2" только изображает уже полученную строку ввода: настоящую форму программа ещё не читает.

Основные арифметические операции можно проверить там же:

Выражение Результат Действие
150 + 50 200 Сложение
150 - 50 100 Вычитание
150 * 2 300 Умножение
150 / 2 75 Деление

Умножение и деление выполняются раньше сложения и вычитания. Скобки задают нужный порядок: (150 + 50) * 2 даст 400. Строки перед вычислениями преобразуем явно, даже если отдельная операция могла бы сделать это сама.

5. Соберите расчёт

В script.js оставьте первые пять объявлений из шага 2. Все строки console.log(...) ниже них замените блоком:

const quantity = Number(quantityText);
const totalPrice = unitPrice * quantity + deliveryPrice;

console.log("Название:", itemName);
console.log("Учебные данные:", isTraining);
console.log("Количество:", quantity);
console.log("Итого:", totalPrice);

В console.log можно передать несколько значений через запятую: сначала подпись, затем значение. Подпись в кавычках — текст, имя без кавычек — обращение к переменной.

Формула: цена одного набора × количество + одна доставка. Сначала строка превращается в число, затем вычисляется сумма.

Сохраните файл и обновите главную. Ожидаемый вывод:

Название: Учебный набор
Учебные данные: true
Количество: 2
Итого: 350

Самопроверка изменением: в исходной строке let quantityText = "2"; замените "2" на "3", сохраните файл и обновите страницу. Теперь количество — 3, итог — 500. Затем верните "2" и снова обновите: итог — 350.

Программа вычисляет сумму при запуске. Редактирование файла без сохранения и обновления страницы не запускает расчёт заново.

6. Пустой текст ещё не означает корректное число

В строке консоли браузера, по одному, проверьте:

Number("")

Number("два")

Первое выражение даёт 0: JavaScript так преобразует пустую строку. Это не доказывает, что человек ввёл количество. Второе даёт NaN — специальное числовое значение, означающее неудачный числовой результат. Умножение такого значения на цену тоже даст NaN.

Number преобразует данные, но само по себе не проверяет допустимость количества. В нашей сохранённой программе используем известную строку "2". Проверять пустой ввод и показывать сообщение пользователю научимся после знакомства с условиями и обработкой формы.

7. Покажите один результат

Сохраните проект с quantityText = "2". Покажите преподавателю главную страницу, подключение script.js и консоль с итогом 350. Затем измените количество в файле на "3", сохраните, обновите и покажите итог 500. Объясните своими словами разницу между "2" + 1 и Number("2") + 1.

Отдельный письменный отчёт не требуется. После показа верните исходное количество и сохраните папку проекта.

Если что-то не получилось Что проверить
В консоли нет вывода Открыта ли главная, сохранены ли оба файла, совпадает ли путь src с именем JS-файла
Красная ошибка и программа остановилась Номер строки справа от ошибки; кавычки, скобки, написание имени
ReferenceError Имя написано одинаково и объявлено выше места использования
NaN вместо суммы В quantityText должны быть цифры без слов; для начала верните "2"
