Вариант 13 — Спорт после пар

Создайте в MIT App Inventor проект Variant13. Название приложения — «Спорт после пар · V13». Используйте только номер варианта, без фамилии.

Это одно задание на две пары. На паре 6 соберите главный экран и каталог. На паре 7 завершите форму, подключите пять переходов и проверьте проект.

Макеты экранов

На сайте переключайте макеты названиями экранов. В Obsidian они расположены друг под другом. Системные поля и кнопки App Inventor могут выглядеть немного иначе; соблюдать нужно структуру и свойства из задания.

Общие требования

  • Ровно три экрана: Screen1, SectionsScreen, TrainingScreen. Установите Scrollable: true; для длинного каталога или формы прокрутка допустима.
  • Свойство Title: у Screen1 — «Спорт после пар · V13», у SectionsScreen — «Секции · V13», у TrainingScreen — «Запись на занятие · V13».
  • Фон — #EAF7F5, текст — #183E39. Основные кнопки — #176B64 с текстом #FFFFFF.
  • Второстепенные кнопки, поля и блоки каталога — белые с основным цветом текста.
  • Заголовки: FontSize: 24, FontBold: true; названия позиций: 18, полужирные; обычный текст: 14–16.
  • Корневой VerticalArrangement занимает всю ширину: Width: Fill parent. Горизонтальные строки собирайте в HorizontalArrangement.
  • Изображения сохраняют пропорции. Используйте иллюстрации в конце листа либо свои по тем же сюжетам.
  • На каждом экране подпись «Учебный прототип · Вариант 13».
  • Имена компонентов — английские, по таблицам; надписи для пользователя — русские.
  • Нет перекрытий и обрезанных надписей. Расчёты, обработка формы и сохранение данных не требуются.

Первая пара: главный экран и каталог

Screen1

Расположение: Заголовок и пояснение → широкое изображение → описание → две кнопки друг под другом.

Компонент Имя Текст или содержание
Label LabelTitle Найдите свою тренировку
Label LabelSubtitle Движение, общение и новые навыки
Image ImageCover Иллюстрация первой позиции каталога
Label LabelIntro Три предложения для выбора. Движение, общение и новые навыки.
Button ButtonCatalog Открыть каталог
Button ButtonForm Выбрать занятие
Label LabelVariant Учебный прототип · Вариант 13

ButtonCatalog — основная, ButtonForm — второстепенная. Контейнеры назовите VerticalArrangementMain, HorizontalArrangementHero (если изображение рядом с текстом), HorizontalArrangementActions (если кнопки рядом).

SectionsScreen

LabelCatalogTitle — «Секции»; LabelCatalogIntro — «Выберите одну из трёх позиций».

Расположение: В каждой строке изображение слева, три надписи справа.

Позиция Название Характеристика Описание Компонент изображения
1 Бадминтон Зал А · 60 минут Парные упражнения и точность движений ImageItem1
2 Волейбол Зал Б · 90 минут Командная игра и работа с мячом ImageItem2
3 Растяжка Студия · 45 минут Спокойные упражнения на гибкость ImageItem3

В каждой позиции три Label: LabelItem1Name, LabelItem1Info, LabelItem1Description. Для позиций 2 и 3 замените цифру. Контейнеры — HorizontalArrangementItem1–3 для изображения сбоку или VerticalArrangementItem1–3 для изображения сверху. Группы надписей — VerticalArrangementText1–3.

Внизу рядом разместите ButtonCatalogBack — «На главную» (второстепенная) и ButtonCatalogForm — «Выбрать занятие» (основная). Под ними LabelCatalogVariant с номером варианта.

Промежуточная сдача: покажите главный экран, каталог и дерево Components; сохраните проект с созданным третьим экраном.

Вторая пара: форма и общая навигация

TrainingScreen

LabelFormTitle — «Запись на занятие».

Расположение: Поля 1, 2, 3 → два флажка → ползунок. Кнопки внизу рядом.

Три поля в порядке сверху вниз:

Номер поля Подпись и поле Текст подписи Свойства поля
1 LabelItemPrompt + TextBoxItem Название секции Hint: Например, Бадминтон
2 LabelCountPrompt + TextBoxCount Количество занятий Text: 2; NumbersOnly: true
3 LabelCommentPrompt + TextBoxComment Пожелания к тренировке Hint: Опишите ваши пожелания; MultiLine: true

Каждое поле имеет отдельную видимую подпись. Многострочное поле высотой не менее двух строк; поля занимают ширину контейнера.

Остальные элементы:

Компонент Имя Текст или свойства
CheckBox CheckBoxOption1 Нужен инвентарь; отмечен
CheckBox CheckBoxOption2 Первое занятие; не отмечен
Label LabelSliderPrompt Интенсивность
Slider SliderLevel MinValue: 1; MaxValue: 5; ThumbPosition: 2
Два Label LabelSliderMin, LabelSliderMax Лёгкая; Высокая
Button ButtonFormBack Назад — второстепенная
Button ButtonSubmit Отправить — основная
Label LabelFormVariant Учебный прототип · Вариант 13

Подписи ползунка стоят рядом в HorizontalArrangementSliderLabels. Его положение демонстрационное; вычисления и вывод значения в надпись не нужны. ButtonSubmit остаётся визуальным элементом, без обработчика отправки.

Подключите пять переходов

Экран Событие кнопки Блок из Control
Screen1 ButtonCatalog.Click open another screen → SectionsScreen
Screen1 ButtonForm.Click open another screen → TrainingScreen
SectionsScreen ButtonCatalogForm.Click open another screen → TrainingScreen
SectionsScreen ButtonCatalogBack.Click close screen
TrainingScreen ButtonFormBack.Click close screen

Как соединить блоки: общая инструкция седьмой пары. Для возврата закрывайте дополнительный экран; новый Screen1 не открывайте. Передача данных между экранами не нужна.

Проверка и сдача

  1. Проверьте маршрут: главная → каталог → форма → назад в каталог → назад на главную.
  2. Проверьте маршрут: главная → форма → назад на главную.
  3. Повторите оба маршрута трижды. Форма возвращается туда, откуда была открыта.
  4. Сверьте расположение изображений, порядок позиций и полей, цвета и начальные состояния элементов со своим вариантом.
  5. Сдайте Variant13.aia и три снимка экранов. При показе найдите заданный преподавателем компонент, измените его свойство и объясните назначение.

Изображения для работы

Сохраните иллюстрации и загрузите в Media проекта. Первую используйте также в ImageCover. Собственные изображения по тем же сюжетам допустимы; расположение компонентов должно сохраниться.
