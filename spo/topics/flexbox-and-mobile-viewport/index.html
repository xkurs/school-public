Flexbox, viewport и адаптивный интерфейс мобильной страницы

Подготовьтесь заранее

Ещё на первых двух практических парах сохраните эту статью с заданиями на телефон: сделайте скриншоты или сохраните страницу. Откройте сохранённое без интернета и убедитесь, что видны все условия, код и таблицы. В аудитории третьей пары плохая связь; рассчитывать на загрузку там нельзя. Сохраняйте учебную страницу сайта: служебный ключ преподавателя в неё не входит.

На этой паре работаем без компьютеров. Телефон нужен только для чтения сохранённого задания; все ответы пишем на бумаге. Если доступен заранее подготовленный печатный лист с условиями, его можно использовать вместо телефона.

Сегодня разберём три простые вещи: какой элемент управляет расположением карточек, чем отличаются строка, столбец и перенос, зачем странице настройка viewport. Внедрять Flexbox в свой проект будем на следующей компьютерной практике.

Flexbox: родитель и его дети

Flexbox помогает располагать элементы рядом или друг под другом. Для этого родителю задают display: flex. Этот родитель называется контейнером. Правило управляет только его непосредственными детьми.

Селектор указывает, к каким элементам относится правило. Свойство и значение задают действие.

Запись Что означает
.menu Селектор: элементы с class="menu"
display: flex Включить Flexbox у выбранного элемента
flex-direction: row Располагать детей в строку
flex-direction: column Располагать детей в столбец
flex-wrap: wrap Разрешить перенос на следующую строку
gap: 12px Оставить промежуток между элементами

В этой статье используем обычное направление текста слева направо и порядок элементов из HTML. Для строки можно разрешить перенос через wrap или запретить через nowrap. nowrap — значение по умолчанию. В реальном браузере карточки могут сжиматься. В бумажных схемах ниже отдельно задано, что их размер сохраняется: здесь изучаем только порядок и перенос.

row:                  column:             row + wrap:
[1] [2] [3]           [1]                  [1] [2]
                      [2]                  [3]
                      [3]

Справа показан случай, когда места хватает на две карточки, но не на три. Перенос сохраняет порядок: сначала 1, затем 2, затем 3.

Разобранный пример: две кнопки

Нужно расположить две кнопки рядом. Места для обеих хватает.

<nav class="actions">
  <button>Сохранить</button>
  <button>Отмена</button>
</nav>

Ищем общего родителя кнопок: это nav с классом actions. Значит, правило назначаем .actions.

.actions {
  display: flex;
  flex-direction: row;
  gap: 12px;
}
Что определяем Ответ для примера
Селектор контейнера .actions
Непосредственные дети Два элемента button
Расположение [Сохранить] [Отмена]

Если внутри кнопки появится span, он будет ребёнком кнопки, а не непосредственным ребёнком nav. Внешний контейнер продолжит располагать две целые кнопки.

Viewport: страница на телефоне

Viewport — область просмотра страницы в браузере. Чтобы мобильный браузер использовал ширину устройства для вёрстки и исходный масштаб 1, в каждой странице внутри head записывают одну строку:

<meta name="viewport" content="width=device-width, initial-scale=1">
Фрагмент Назначение
width=device-width Использовать ширину устройства для вёрстки в CSS-пикселях
initial-scale=1 Задать исходный масштаб 1

Строка не запрещает человеку увеличивать страницу. Она сама не перестраивает карточки: их расположением управляет CSS.
