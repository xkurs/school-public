Создание проекта и первой страницы, подключение стилей и скрипта

1. Свой номер, знакомая тема

Откройте свой вариант 01–39. В разделе «Содержание главной страницы» найдите строки «Название приложения» и «Короткое пояснение». Название используйте во вкладке и главном заголовке, пояснение — в первом абзаце. Пошаговый способ реализации находится здесь, а лист варианта даёт ваши тексты.

В примере ниже показан вариант 01. В своей работе замените его номер и содержание.

Итог пары: страница вашего приложения открывается из папки проекта, получает цвет из CSS и выводит сообщение JavaScript в консоль.

2. Создайте три файла

VariantNN-web/
  index.html
  style.css
  app.js

NN замените своим номером: например, 04.

В редакторе создайте пустые файлы с этими именами. Проверьте расширения: index.html.txt — другое имя.

3. Добавьте страницу

В index.html сохраните этот учебный образец в UTF-8:

<!doctype html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>На тропе · V01</title>
  <link rel="stylesheet" href="style.css">
  <script src="app.js" defer></script>
</head>
<body>
  <h1>На тропе · V01</h1>
  <p>Выберите прогулку для небольшой компании</p>
</body>
</html>

Сначала откройте файл в браузере и убедитесь, что видны заголовок и абзац. Разбор устройства документа продолжится на следующей паре.

4. Сделайте страницу своей

Замените название во вкладке, заголовок и описание на содержание своего варианта.

изменить файл → сохранить → обновить страницу

Проверка: название во вкладке и заголовок относятся к вашему варианту. После закрытия и повторного открытия файла изменения остаются.

5. Подключите оформление

В style.css запишите:

body {
  font-family: sans-serif;
  margin: 24px;
}
h1 {
  color: darkgreen;
}

Сохраните и обновите страницу. Затем самостоятельно измените цвет заголовка.

Сейчас проверяем подключение CSS. Цвета своего макета и подробную вёрстку разберём позже.

6. Подключите команду

В app.js запишите:

console.log("Открыт вариант 01");

Поставьте свой номер. Сохраните файл, откройте консоль браузера и обновите страницу.

Проверка: в консоли видно сообщение с вашим номером. Эта команда не добавляет текст на страницу.

7. Если изменение не видно

Симптом Что проверить сначала
Старый заголовок Сохранён ли файл и та ли страница открыта
Цвет не изменился Точное имя style.css, путь в href, сохранение
Нет сообщения Точное имя app.js, путь в src, консоль и обновление
Непонятные символы Сохранение HTML в UTF-8 и meta charset

Меняйте одну причину за раз. После каждого исправления обновляйте страницу.

8. Покажите результат

Откройте веб-проект из своей папки и покажите преподавателю:

  • название и описание своего варианта;
  • изменение цвета через CSS;
  • сообщение со своим номером в консоли;
  • сохранённое изменение заголовка после повторного открытия.

Сохраните всю папку VariantNN-web, а не один HTML-файл. Работайте с ней и на следующей паре. Публикация, установка PWA, форма и переходы между тремя экранами сегодня не требуются.
