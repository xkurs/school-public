От визуальных блоков к текстовому коду

Главная мысль: визуальные блоки и текстовый код описывают сходные программные идеи. Меняется запись, а не необходимость думать об алгоритме.

Покажите знакомую цепочку счётчика из предыдущих занятий. Есть начальное значение, действие «Добавить» и действие «Сбросить». В текстовой записи на JavaScript это может выглядеть так:

let count = 0;

function add() {
  count += 1;
  return count;
}

function reset() {
  count = 0;
  return count;
}

Разберите по одной строке: let count = 0 задаёт состояние; function add() называет действие; count += 1 меняет число; return count возвращает результат. Здесь ещё нет кнопки и надписи — это только логика. Позднее мы свяжем её с интерфейсом веб-страницы.

Попросите студентов вручную проследить add(); add(); reset(); add(). После первых двух вызовов число 2, после сброса 0, после последнего вызова 1. Затем покажите небольшую ошибку: если написать count + 1 без присваивания, значение не изменится. Пусть объяснят, почему.

Спросите, что удобнее видеть в блоках, а что в тексте. Не надо объявлять конструктор «не настоящим программированием»: в нём уже были переменные, события, условия и ошибки. Теперь мы учимся записывать их более гибко.

Затем покажите, как использовать ИИ для подсказки: сначала студент сам предсказывает результат, потом спрашивает «Проверь мой ход мысли; дай намёк, не готовое решение», наконец вручную сверяет ответ. Если чат недоступен, эту роль берёт сосед или преподаватель.

Итог: студент связывает знакомые блоки с строками кода и правильно предсказывает состояние после последовательности вызовов.
