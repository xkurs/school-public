HTML: структура документа, смысловые разделы, текст, ссылки и изображения

1. Откройте свою страницу

Откройте VariantNN-web/index.html в редакторе и браузере. В своём листе варианта держите открытыми разделы «Содержание главной страницы», «Содержание каталога» и «Изображения для работы».

Сегодня добавим: понятные части страницы, ссылку и изображение.

Если проект ещё не запускается, сначала проверьте его по инструкции предыдущей пары.

2. Вкладка и страница — разные места

<head>
  <title>На тропе · V01</title>
</head>
<body>
  <h1>На тропе · V01</h1>
</body>

head хранит сведения о документе. body содержит то, что браузер показывает на странице.

Найдите: какую строку изменить, чтобы переименовать только вкладку?

3. Теги обозначают роль текста

<h1>На тропе · V01</h1>
<p>Маршруты выходного дня</p>

h1 — главный заголовок. p — абзац. Закрывающий тег содержит /.

Ваш ход: добавьте абзац из строки «Описание» своего варианта. Название приложения оставьте главным заголовком, а строку «Заголовок главной» используйте как заголовок содержательного раздела на следующем шаге.

4. Разделы помогают читать страницу

<header>
  <h1>На тропе · V01</h1>
</header>
<main>
  <section>
    <h2>О приложении</h2>
    <p>Маршруты выходного дня</p>
  </section>
</main>
<footer>Учебный прототип · Вариант 01</footer>

header — вводная часть. main — основное содержание. section — смысловой раздел с заголовком. footer — завершающая часть.

Вложенные элементы записываются внутри родительских. Отступы помогают увидеть эту вложенность.

5. Список объединяет пункты

<h2>Что можно выбрать</h2>
<ul>
  <li>Лесная тропа</li>
  <li>Берег реки</li>
</ul>

ul — список без нумерации. Каждый пункт находится в li.

Попробуйте: возьмите первые два названия из таблицы «Содержание каталога» своего варианта и запишите их списком. Карточки и расположение изображений оформим позднее.

6. Ссылка ведёт к цели

Сначала пометьте раздел:

<section id="about">
  <h2>О приложении</h2>
  <p>Маршруты выходного дня</p>
</section>

Затем добавьте перед ним ссылку:

<a href="#about">О приложении</a>

href задаёт цель перехода. Здесь #about указывает на раздел с id="about" в той же странице.

Проверьте: нажмите ссылку. В адресе должен появиться #about. На короткой странице прокрутка может быть незаметна.

7. Изображению нужен файл и описание

Положите одно изображение своей темы в папку проекта. Например:

Variant01-web/
  index.html
  images/
    forest.png

<img src="images/forest.png"
     alt="Лес на прогулочном маршруте"
     width="240">

src — путь к файлу. alt — текстовая альтернатива содержательному изображению. У img нет закрывающего тега.

В своём проекте используйте собственное имя файла и подходящее описание. Изображения доступны в листе вашего варианта; сохраните выбранное изображение отдельно от снимка всего макета.

8. Проверьте свой главный экран

  • Во вкладке и на странице указан ваш вариант.
  • Есть header, main, раздел с заголовком и footer.
  • Два названия из своего каталога оформлены списком.
  • Ссылка ведёт к существующему разделу.
  • Видно изображение своей темы, у него есть осмысленный alt.

Сохраните файлы и откройте страницу заново. Покажите преподавателю, где заканчивается раздел и где начинается следующий элемент.

Полный каталог, форма и точная компоновка макета будут следующими шагами.
