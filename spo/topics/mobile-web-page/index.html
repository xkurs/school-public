Мобильная веб-страница: HTML, CSS, JavaScript и инструменты разработчика

1. Ваш вариант продолжается

Откройте свой вариант 01–39. Сохраните его номер и тему.

Было: интерфейс в App Inventor. Следующий шаг: веб-страница того же приложения.

В своём листе найдите название приложения, основное изображение и название перехода к каталогу. Сопоставьте их с макетом и покажите соседу. Пока определяем назначение элементов; способ веб-реализации разберём по шагам в занятиях.

2. Браузер показывает страницу

Браузер читает файлы и строит страницу на экране.

файл страницы → браузер → видимый интерфейс

Один и тот же HTML-файл можно открыть на разных компьютерах. Отображение зависит также от ширины окна, шрифтов и браузера.

Попробуйте: сузьте окно браузера. Что стало неудобно читать или нажимать?

3. HTML задаёт содержание

HTML — язык разметки. Он обозначает роль содержимого: заголовок, абзац, ссылку, изображение.

<h1>На тропе · V01</h1>
<p>Маршруты выходного дня</p>

Браузер покажет заголовок и отдельный абзац. Обозначения в угловых скобках называются тегами.

Ваш ход: какие слова здесь нужно заменить для своего варианта?

4. CSS задаёт оформление

CSS описывает, как выглядят элементы страницы.

h1 {
  color: darkgreen;
}

Эта запись выбирает заголовки h1 и задаёт цвет текста.

Предскажите: что изменится, если заменить darkgreen на navy? Изменится ли текст заголовка?

5. JavaScript выполняет действие

JavaScript — язык программирования. Браузер выполняет написанные на нём команды.

console.log("Открыт вариант 01");

Сообщение появится в консоли разработчика. На самой странице оно не появится.

Позже обработчик нажатия сможет проверить ввод и изменить страницу. Сегодня достаточно увидеть запуск готовой команды.

Обсудите: кнопку нужно переименовать, перекрасить и научить считать. В каких частях проекта будут изменения?

7. Инструменты браузера помогают проверять

Откройте меню браузера, найдите «Инструменты разработчика» и вкладку Console / Консоль. Обычно помогают F12 или Ctrl+Shift+I.

Найдите сообщение учебной страницы. Для осмотра HTML используйте вкладку Elements / Элементы или Inspector / Инспектор.

Изменение текста в инспекторе влияет на текущее отображение. После обновления страницы браузер снова прочитает сохранённый файл.

Проверка: измените заголовок в инспекторе и обновите страницу. Что сохранилось?

На следующей паре вы создадите файлы и измените страницу так, чтобы результат сохранялся после обновления.
