HTML-форма: поля, подписи, кнопки и встроенная проверка ввода

Что получится

Продолжаем работу после создания каталога: добавляем к главной и каталогу страницу формы. Работаем в прежнем проекте: после каждого объяснения сразу выполняем действие за компьютером.

Текущий набор индивидуальных заданий — используйте свой номер, названия полей, три позиции каталога и начальные значения. Пример ниже — учебный вариант 00 «Техника дома», отдельный от студенческих вариантов. Заменяйте его данные своими; вариант 00 студентам не назначается.

Сегодня форма помогает ввести данные и обнаружить пропуски. Приложение пока не сохраняет заявку и не обрабатывает её программой. Используйте только вымышленные учебные данные.

Схема показывает состав формы, а не точное оформление: вид полей зависит от браузера. Справа подписаны HTML-элементы, которые будем добавлять по одному.

Подготовьте третью страницу

Сначала проверьте переходы между index.html и catalog.html из предыдущей работы. Если каталог не завершён, сохраните сделанное: для формы нужны его три названия из своего листа, а не готовое оформление.

Создайте рядом с ними form.html. Вставьте в пустой файл:

<!doctype html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Форма — Техника дома · V00</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <header>
    <p>Техника дома · V00</p>
    <nav>
      <a href="index.html">Главная</a>
      <a href="catalog.html">Каталог</a>
      <a href="form.html">Форма</a>
    </nav>
  </header>
  <main>
    <h1>Заказ техники</h1>
    <p>Учебная форма. Данные пока не сохраняются.</p>
    <form method="get">
    </form>
    <p><a href="index.html">Назад</a></p>
  </main>
  <footer>
    <p>Учебный прототип · Вариант 00</p>
  </footer>
</body>
</html>

Замените название приложения, формы и подпись своими. В nav обеих прежних страниц добавьте третью ссылку на form.html. На главной после ссылки к каталогу добавьте ссылку к форме с надписью из строки «Название перехода к форме» своего листа.

Проверка: откройте все три страницы через меню, затем вернитесь из формы по «Назад» на главную.

Как связаны подпись и поле

label — видимая подпись. for у подписи совпадает с id поля: при нажатии на подпись браузер выбирает связанное поле. Каждый id на странице должен быть уникальным.

name — имя данных при отправке формы. Это другая роль: одного id для передачи значения недостаточно. В примерах имена служебные, их можно сохранить в любом варианте.

placeholder — временная подсказка внутри поля. Она исчезает при вводе и не заменяет подпись.

Выберите позицию каталога

В form.html, между <form method="get"> и </form>, добавьте:

<p>
  <label for="item">Товар</label>
  <select id="item" name="item" required>
    <option value="">Выберите из списка</option>
    <option value="fridge">Холодильник</option>
    <option value="washer">Стиральная машина</option>
    <option value="kettle">Электрочайник</option>
  </select>
</p>

select — список выбора, option — его пункт. Подпись «Товар» замените подписью выбора позиции из своего листа. Видимые названия замените тремя названиями из каталога своего варианта. Значения value сделайте разными; можно использовать item1, item2, item3.

Первая строка имеет пустое value="": это приглашение сделать выбор. required требует непустого выбора. Без пустого первого пункта браузер сразу выбрал бы первую позицию, и студент мог бы не заметить необходимость выбора.

Сохраните и обновите: список открывается, видны три ваши позиции.

Введите целое количество

Внутри той же формы после блока со списком добавьте:

<p>
  <label for="quantity">Количество единиц</label>
  <input id="quantity" name="quantity" type="number"
         min="1" step="1" value="1" required>
</p>

Вместо «Количество единиц» возьмите подпись числового поля из своего листа (строка «Целое количество от 1»), вместо 1 — его начальное значение. Порядок строк формы в разных вариантах может отличаться: после знакомства с элементами расположите блоки по порядку своего листа.

Атрибут Для чего нужен
type="number" Числовое поле
min="1" Минимум — единица
step="1" Допустимы целые значения с шагом один
value="1" Начальное значение
required Поле нельзя оставить пустым

input не имеет закрывающего тега. Числовое поле само не считает стоимость и не проверяет наличие товара на складе: это будущая программная логика.

Добавьте несколько строк текста

После числового поля, внутри формы, добавьте:

<p>
  <label for="notes">Комментарий к заказу</label>
  <textarea id="notes" name="notes" rows="4"
            placeholder="Например, удобный день доставки"></textarea>
</p>

Замените подпись и подсказку данными своего варианта. rows="4" задаёт исходную высоту в строках. У textarea есть закрывающий тег; текст между тегами был бы начальным содержимым.

Это необязательное поле: required здесь не добавляем. Напишите две строки вымышленного текста и убедитесь, что перенос работает.

Добавьте два независимых флажка

Следом, внутри формы, добавьте:

<p>
  <input id="extra1" name="extra1" type="checkbox" value="yes" checked>
  <label for="extra1">Нужна доставка</label>
</p>
<p>
  <input id="extra2" name="extra2" type="checkbox" value="yes">
  <label for="extra2">Нужна установка</label>
</p>

Замените подписи двумя возможностями своего варианта. Атрибут checked ставьте только у тех, которые по листу выбраны в начале. Для отключённого флажка уберите атрибут полностью: checked="false" всё равно означает его присутствие и начальный выбор.

У этих флажков разные id и name. Можно включить оба, один или ни одного. Нажмите на текст каждой подписи: должен переключиться соответствующий флажок.

Добавьте шкалу

Следующий блок внутри формы:

<p>
  <label for="level">Срочность заказа</label>
  <input id="level" name="level" type="range"
         min="1" max="5" step="1" value="3">
  <span>1 — Не срочно; 5 — Срочно</span>
</p>

Подпись, начальное value и названия краёв возьмите из своего листа. Диапазон остаётся от 1 до 5.

range показывает ползунок. Точное текущее число рядом автоматически не появляется: для такого индикатора позднее понадобится программный обработчик. Сейчас достаточно подписи, границ и работающего ползунка.

Добавьте кнопку проверки

После всех полей, перед </form>, добавьте:

<button type="submit">Проверить заказ</button>

Надпись возьмите из строки «Текст кнопки отправки» своего варианта. submit запускает штатную отправку формы, а перед ней браузер проверяет ограничения полей. Ссылка «Назад» остаётся за пределами формы и просто открывает главную.

В примере у form задан method="get", адрес action не указан. После успешной проверки браузер открывает текущую страницу с параметрами из полей в адресе. Например, выбранная позиция передаётся под именем item. В локальном учебном проекте серверного обработчика нет: страница может перезагрузиться, значения вернуться к начальным. Это не подтверждение сохранения заявки.

Не добавляйте чужой серверный адрес. Не вводите настоящие телефоны, пароли или другие личные сведения: GET помещает данные в адресную строку.

Испытайте ограничения

Проводите проверки по одной. Перед каждой новой проверкой заполните остальные обязательные поля корректно.

Действие Ожидаемый результат
Оставить «Выберите из списка», нажать кнопку Браузер просит выбрать позицию
Выбрать позицию, очистить количество, нажать кнопку Браузер требует количество
Ввести 0 и нажать кнопку Значение меньше минимума не принимается
Ввести 1.5 и нажать кнопку Дробное значение не соответствует шагу; некоторые браузеры ограничивают его ввод
Выбрать позицию, ввести 3, оставить комментарий пустым Встроенная проверка допускает отправку, поскольку комментарий необязателен

Текст и вид сообщений зависят от браузера. Проверяется поведение, а не совпадение фразы с образцом. Если дробь с точкой не вводится в вашей локали, попробуйте разделитель, который принимает поле; приём дроби и возможность успешной отправки — разные проверки.

После успешной отправки посмотрите адрес и объясните, откуда берутся имена параметров. Невыбранный checkbox обычно не включается в данные формы. Затем откройте form.html по меню заново для проверки исходных значений.

Покажите результат

  1. В папке есть три страницы, style.css и изображения; меню открывает каждую страницу.
  2. Форма соответствует своему варианту: три позиции, количество, многострочный текст, два флажка и шкала.
  3. Все поля имеют видимые связанные подписи; id не повторяются, у полей есть name.
  4. Продемонстрированы четыре случая: пропуск выбора, пустое количество, ноль и корректное заполнение.
  5. По просьбе преподавателя измените начальное число или подпись в исходнике, сохраните и покажите изменение после открытия страницы без параметров.

Сохраните всю папку. Если остаётся время, проверьте клавиатуру: Tab переводит фокус, пробел переключает флажок, стрелки меняют выбор и положение ползунка. Исправьте непонятные подписи.
