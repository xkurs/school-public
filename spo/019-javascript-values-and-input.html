JavaScript — переменные, типы, операции и преобразование пользовательского ввода

HTML задаёт содержимое страницы, CSS — оформление, JavaScript позволяет выполнять действия и вычисления. На этой практике разберём первый расчёт в script.js, затем самостоятельно напишем расчёт для своего проекта и проверим его в консоли браузера.

Результат: свой script.js с расчётом по теме вашего прежнего проекта. Вы сможете изменить исходное количество, сверить результат со своим заданием и объяснить преобразование строки в число. Ниже сначала разобран общий учебный пример.

Продолжайте свой веб-проект после адаптации страниц или воспользуйтесь демонстрационным примером. В нём один набор стоит 150 условных рублей, доставка — 50. После разбора подставьте свои значения и проверьте вывод в консоли. Добавлять эти числа в HTML-каталог и переделывать форму не требуется.

В разделе «Демонстрационный пример» есть задание, HTML-страница и готовый код расчёта.

1. Подключите файл

В своей папке рядом с index.html и style.css создайте обычный текстовый файл script.js. Проверьте расширение: script.js.txt браузер не найдёт по нашему пути.

В index.html, между <head> и </head>, сразу после подключения CSS добавьте одну строку:

HTML
<script src="script.js" defer></script>

src указывает путь к файлу. defer откладывает выполнение до завершения разбора HTML. Вставлять JavaScript внутрь этого тега не нужно: программа хранится в отдельном файле. На этой практике достаточно подключить её на главной странице.

В пустом script.js напишите:

JavaScript
console.log("Расчёт запущен");

Сохраните оба файла. Откройте главную в браузере, нажмите F12 и выберите вкладку Console / Консоль. Если F12 не открывает инструменты, используйте меню браузера → дополнительные инструменты → инструменты разработчика. Обновите страницу.

Самопроверка: в консоли есть строка «Расчёт запущен». На самой странице новый текст не появляется: console.log(...) выводит сообщение в консоль. В скобках — то, что нужно вывести; точка с запятой завершает команду.

2. Дайте значениям имена

В script.js замените пробную строку следующим блоком:

JavaScript
const itemName = "Учебный набор";
const unitPrice = 150;
let quantityText = "2";
const deliveryPrice = 50;
const isTraining = true;

console.log(itemName);
console.log(quantityText);
console.log(isTraining);

Переменная — именованное место для значения. = записывает значение справа в имя слева. Команды выполняются сверху вниз.

Запись Что означает
const unitPrice = 150; Объявить имя unitPrice и записать число 150; повторное присваивание запрещено
let quantityText = "2"; Объявить имя quantityText и записать строку; позже можно присвоить другое значение
console.log(unitPrice); Посмотреть значение по его имени

Имена чувствительны к регистру: unitPrice и UnitPrice — разные имена. В числах не пишем единицу измерения: 150, а не 150 рублей. Текст записываем в кавычках.

Сохраните файл и обновите страницу. В консоли должны появиться название, количество и true. Вид кавычек и цвет значений зависят от браузера.

Маленький опыт: сразу после строки let quantityText = "2"; временно вставьте:

JavaScript
quantityText = "3";

После сохранения и обновления выводится уже 3. При повторном присваивании let не пишут. Удалите временную строку и обновите страницу: снова выводится 2. const используем там, где повторного присваивания в программе не планируем. Редактировать исходный текст строки с const перед новым запуском можно.

3. Различайте три типа

Значение имеет тип: он определяет, как с ним работает программа.

Тип Примеры Назначение
Строка — string "Учебный набор", "2", "" Текст, включая цифры в кавычках; "" — пустой текст
Число — number 150, 2, 1.5 Вычисления; дробная часть отделяется точкой
Логическое значение — boolean true, false «Да» или «нет», без кавычек

isTraining = true обозначает, что пример учебный. Пока мы только выводим этот признак: он не меняет формулу.

В конец script.js, после трёх строк вывода, добавьте:

JavaScript
console.log(typeof quantityText);
console.log(typeof unitPrice);
console.log(typeof isTraining);

typeof показывает тип значения. Сохраните и обновите страницу. Последние три строки консоли — string, number, boolean. Поэтому одинаково выглядящие при выводе "2" и 2 ещё не означают одинаковые данные.

4. Проверьте сложение и преобразование

Следующие два выражения вводите по одному в строку консоли браузера, нажимая Enter. Перед запуском попробуйте предсказать результат:

JavaScript
"2" + 1
JavaScript
Number("2") + 1

В первом случае получится строка "21": + присоединяет текст, если один из этих операндов — строка. Во втором — число 3: Number("2") преобразует строку в число, и затем выполняется сложение.

Текст
"2" — строка → Number("2") → 2 — число → 2 + 1 → 3

При чтении значения поля веб-страницы программа обычно получает строку, даже если это числовое поле. К чтению полей перейдём позже. Сейчас quantityText = "2" только изображает уже полученную строку ввода: настоящую форму программа ещё не читает.

Основные арифметические операции можно проверить там же:

Выражение Результат Действие
150 + 50 200 Сложение
150 - 50 100 Вычитание
150 * 2 300 Умножение
150 / 2 75 Деление

Умножение и деление выполняются раньше сложения и вычитания. Скобки задают нужный порядок: (150 + 50) * 2 даст 400. Строки перед вычислениями преобразуем явно, даже если отдельная операция могла бы сделать это сама.

5. Соберите расчёт

В script.js оставьте первые пять объявлений из шага 2. Все строки console.log(...) ниже них замените блоком:

JavaScript
const quantity = Number(quantityText);
const totalPrice = unitPrice * quantity + deliveryPrice;

console.log("Название:", itemName);
console.log("Учебные данные:", isTraining);
console.log("Количество:", quantity);
console.log("Итого:", totalPrice);

В console.log можно передать несколько значений через запятую: сначала подпись, затем значение. Подпись в кавычках — текст, имя без кавычек — обращение к переменной.

Формула: цена одного набора × количество + одна доставка. Сначала строка превращается в число, затем вычисляется сумма.

Сохраните файл и обновите главную. Ожидаемый вывод:

Текст
Название: Учебный набор
Учебные данные: true
Количество: 2
Итого: 350

Самопроверка изменением: в исходной строке let quantityText = "2"; замените "2" на "3", сохраните файл и обновите страницу. Теперь количество — 3, итог — 500. Затем верните "2" и снова обновите: итог — 350.

Программа вычисляет сумму при запуске. Редактирование файла без сохранения и обновления страницы не запускает расчёт заново.

6. Пустой текст ещё не означает корректное число

В строке консоли браузера, по одному, проверьте:

JavaScript
Number("")
JavaScript
Number("два")

Первое выражение даёт 0: JavaScript так преобразует пустую строку. Это не доказывает, что человек ввёл количество. Второе даёт NaN — специальное числовое значение, означающее неудачный числовой результат. Умножение такого значения на цену тоже даст NaN.

Number преобразует данные, но само по себе не проверяет допустимость количества. В разобранном примере используем известную строку "2". В самостоятельной работе исходную строку возьмите из своего задания. Проверять пустой ввод и показывать сообщение пользователю научимся после знакомства с условиями и обработкой формы.

7. Выполните свой вариант и покажите результат

После разбора примера напишите в script.js расчёт для одной позиции вашего проекта. Выберите количество, значение на единицу и разовую добавку для всего заказа. Заранее вычислите ожидаемый итог, затем сравните его с выводом консоли. Если своего проекта нет, измените исходные числа в примере и повторите проверку. При необходимости возвращайтесь к объяснению переменных, типов и преобразования выше.

Сохраните проект, обновите главную страницу и сверьте один запуск с текстовым образцом консоли в своём листе. Покажите преподавателю подключение script.js и полученный вывод. Сам итог числом в программу не вписывайте: он должен вычисляться из данных. Второй запуск для сдачи не требуется.

Объясните, какое значение было строкой, где оно стало числом и почему добавочная величина учитывается один раз. Покажите типы исходной строки, полученного количества и результата. Текстовое название и логический признак учебных данных выведите отдельно; условные выражения пока не нужны.

Отдельный письменный отчёт не требуется. После показа сохраните папку проекта с исходными данными своего варианта.

Если что-то не получилось Что проверить
В консоли нет вывода Открыта ли главная, сохранены ли оба файла, совпадает ли путь src с именем JS-файла
Красная ошибка и программа остановилась Номер строки справа от ошибки; кавычки, скобки, написание имени
ReferenceError Имя написано одинаково и объявлено выше места использования
NaN вместо суммы В quantityText должны быть цифры без слов; для начала верните строковое количество из исходных данных
Старый результат Сохраните script.js и обновите страницу; прежний вывод можно очистить кнопкой консоли

Демонстрационный пример

Открыть пример

Это полный постоянный пример преподавателя. Он принадлежит паре 19 и не зависит от смены студенческого комплекта. Для него достаточно двух файлов; переносить прежний трёхстраничный сайт и изображения не нужно.

Задание: собрать учебный расчёт стоимости наборов с одной доставкой. Количество задано строкой, перед вычислением оно преобразуется в число. Итог выводится в консоли браузера. Форма ввода и обработка её элементов в это задание не входят.

Этот расчёт разбирается как образец. Затем студенты самостоятельно пишут расчёт по данным примера или своего сохранённого проекта в script.js, подключённом к прежней главной странице; отдельный HTML ниже нужен для автономного преподавательского показа.

Данные и ожидаемый результат

Все значения вымышлены и используются только для обучения.

Величина Имя Значение
Название itemName Строка "Учебный набор"
Цена одного набора unitPrice Число 150 условных рублей
Количество до преобразования quantityText Строка "2"
Стоимость одной доставки deliveryPrice Число 50 условных рублей
Признак учебных данных isTraining Логическое значение true

Формула: 150 × 2 + 50 = 350. Признак isTraining только выводится, в расчёте не участвует. Доставка прибавляется один раз ко всему заказу.

Файл index.html

Создайте папку Variant00-js. В ней создайте index.html и вставьте весь текст:

HTML
<!doctype html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Учебный расчёт · V00</title>
  <script src="script.js" defer></script>
</head>
<body>
  <main>
    <h1>Учебный расчёт</h1>
    <p>Откройте консоль браузера: результат программы выводится туда.</p>
    <p>Изменяйте количество в файле script.js, сохраняйте и обновляйте страницу.</p>
  </main>
</body>
</html>

Отдельный CSS не требуется. Страница содержит пояснение, а не вычисляемую сумму.

Файл script.js

Рядом с index.html создайте script.js и вставьте весь код:

JavaScript
const itemName = "Учебный набор";
const unitPrice = 150;
let quantityText = "2";
const deliveryPrice = 50;
const isTraining = true;

const quantity = Number(quantityText);
const totalPrice = unitPrice * quantity + deliveryPrice;

console.log("Название:", itemName);
console.log("Учебные данные:", isTraining);
console.log("Количество:", quantity);
console.log("Итого:", totalPrice);

Сохраните оба файла в кодировке UTF-8. Откройте index.html в браузере, затем F12 → Console / Консоль и обновите страницу. Если клавиша не открывает инструменты, выберите их в меню браузера → дополнительные инструменты.

Ожидаемый вывод:

Текст
Название: Учебный набор
Учебные данные: true
Количество: 2
Итого: 350

Проверка изменением

В script.js замените только "2" на "3" в строке объявления quantityText. Сохраните и обновите страницу: ожидаются количество 3 и итог 500. Верните "2", сохраните и обновите: итог снова 350.

В строке консоли браузера проверьте по одному два выражения:

JavaScript
"2" + 1
JavaScript
Number("2") + 1

Получится строка "21" и число 3. У первого выражения + присоединяет текст, у второго складывает числа. В сохранённом расчёте преобразование выполняется отдельной строкой const quantity = Number(quantityText);.

Готово, когда оба файла сохранены, исходный расчёт даёт 350, после изменения количества получается 500 и вы можете объяснить различие двух выражений. Отдельный отчёт и дополнительные обязательные задания не нужны.
