Информатика 11. Количество информации

Главная мысль

Информация — это сведения, которые уменьшают неопределённость и помогают описывать, понимать или изменять объекты и процессы. Количество информации можно оценивать по-разному. В задачах информатики особенно важны алфавитный подход и содержательный подход, связанный с числом возможных равновероятных сообщений.

Что называют информацией

Информация существует не сама по себе, а в сообщении, знаке, изображении, звуке или другом представлении данных. Одни и те же сведения можно передать разными способами: текстом, таблицей, схемой или программой.

Важно различать данные и информацию. Данные — это зафиксированные знаки или значения, а информацией они становятся для получателя тогда, когда имеют смысл и уменьшают неопределённость. Набор символов, значение которого неизвестно, может оставаться данными без полезной для человека информации.

Единицы измерения

В информатике количество информации обычно измеряют в битах и байтах.

  • Бит — минимальная единица информации, принимающая одно из двух значений: 0 или 1.
  • Байт — последовательность из 8 бит.

Основные соотношения:

\[1\ байт = 8\ бит\]
\[1\ Кбайт = 1024\ байт,\quad 1\ Мбайт = 1024\ Кбайт,\quad 1\ Гбайт = 1024\ Мбайт\]

В некоторых технических спецификациях используются десятичные приставки: 1 килобайт принимают равным 1000 байтам. Поэтому при решении задачи нужно смотреть, какое соглашение задано в условии.

Алфавитный подход

Алфавит — множество символов, используемых для записи сообщений. Если алфавит содержит \(N\) различных символов, а каждый символ кодируется одинаковым числом бит, то количество информации в одном символе равно:

\[i = \log_2 N\]

Если сообщение содержит \(K\) символов, его информационный объём равен:

\[I = K \cdot i = K \cdot \log_2 N\]

Формула применима, когда символы кодируются фиксированным одинаковым количеством бит. Если \(N=2^i\), значение \(i\) получается целым. Например, для алфавита из 256 символов один символ требует \(\log_2 256=8\) бит, то есть 1 байт.

Пример 1. Сообщение из символов

Сообщение содержит 100 символов и записано алфавитом из 256 символов. Один символ несёт 8 бит, поэтому:

\[I = 100 \cdot 8 = 800\ бит = 100\ байт\]

Пробелы и знаки препинания также считаются символами, если они входят в записанное сообщение.

Содержательный подход

Пусть произошло одно из \(N\) равновероятных событий. До получения сообщения неопределённость можно выразить числом возможных вариантов. Количество информации в сообщении о том, какой вариант осуществился, вычисляют так:

\[I = \log_2 N\]

Если возможные события неравновероятны, одной этой формулы недостаточно: нужно учитывать вероятности отдельных исходов. Для равновероятных вариантов формула даёт простой и наглядный результат.

Пример 2. Выбор варианта

В тесте 8 равновероятных вариантов ответа. Сообщение о выбранном правильном варианте содержит:

\[I = \log_2 8 = 3\ бита\]

Три бита позволяют закодировать \(2^3=8\) различных вариантов.

Связь количества вариантов и числа бит

Одним битом можно закодировать \(2\) варианта, двумя битами — \(2^2=4\), тремя — \(2^3=8\). Поэтому \(i\) бит позволяют различить:

\[N = 2^i\]

Если число вариантов не является степенью двойки, для фиксированного двоичного кода берут не меньшее целое число бит. Например, для 5 вариантов нужно 3 бита, потому что 2 бит дают только 4 комбинации, а 3 бита — 8.

Информационный объём файла

Размер файла зависит от числа элементов и способа их кодирования. Для текста при фиксированной кодировке можно оценить объём как произведение числа символов на размер одного символа. Для изображения важны ширина, высота, глубина цвета и наличие сжатия.

Например, несжатое изображение размером \(800\times600\) пикселей с глубиной цвета 24 бита на пиксель содержит:

\[800\cdot600\cdot24 = 11\,520\,000\ бит\]

или:

\[11\,520\,000 / 8 = 1\,440\,000\ байт\]

Реальный файл может быть меньше из-за сжатия и особенностей формата.

Главное

  • Бит — минимальная единица информации, байт содержит 8 бит.
  • Для алфавита из \(N\) символов один символ при равномерном кодировании содержит \(\log_2N\) бит.
  • Информационный объём сообщения из \(K\) символов равен \(K\log_2N\).
  • Для \(N\) равновероятных вариантов сообщение о выбранном варианте содержит \(\log_2N\) бит.
  • Всегда нужно учитывать единицы измерения, способ кодирования и наличие сжатия.

Задания для самопроверки

  1. Сколько бит содержит 6 байт?
  2. Сколько информации несёт один символ алфавита из 16 символов при равномерном кодировании?
  3. Найдите объём сообщения из 200 символов, если каждый символ кодируется 8 битами.
  4. Сколько бит нужно, чтобы закодировать 32 равновероятных варианта?
  5. Почему для пяти вариантов требуется не 2, а 3 бита при использовании фиксированного двоичного кода?
  6. Оцените размер несжатого изображения \(100\times100\) пикселей с глубиной цвета 24 бита на пиксель в байтах.
Ответы для самопроверки
  1. \(6\cdot8=48\) бит.
  2. \(\log_2 16=4\) бита.
  3. \(200\cdot8=1600\) бит, или 200 байт.
  4. \(\log_2 32=5\) бит.
  5. Двумя битами можно получить только 4 комбинации, а для 5 вариантов нужна следующая степень двойки: \(2^3=8\).
  6. \(100\cdot100\cdot24/8=30\,000\) байт.
